# シンプルスライド

Markdown で書いた原稿を、そのままスライドとして発表するためのブラウザアプリです。
`index.html` 1 ファイルだけで動き、インストールやアカウントは要りません。
数式(KaTeX)とコードの色付け(Prism)を中に含んでいるため、外部のサービスを読み込まずに動きます。

- `---` の行で区切るとスライドになる
- 数式(行内・別行立て・`\begin{aligned}` など、マクロ定義も可)
- 画像はドラッグ & ドロップか Ctrl+V で貼り、マウスで移動・拡大縮小できる
- 配色は 5 種類(白・黒板・えんじ・紫紺・ペールブルー)
- 発表中は、レーザーポインタとペン(ペンタブレットの筆圧と側面ボタンの消しゴムに対応)を使える
- 段階表示(クリックごとに続きを出す)、2 段組、見出し付きの囲み枠
- 印刷で、1 ページに 1 枚ずつの配布資料や PDF を作れる

## 使い方

公開版は https://slide.sapp.jp で使えます。
ダウンロードした `index.html` をブラウザで直接開いても使えます。

1. 公開版か `index.html` を、ブラウザ(Edge・Chrome など)で開きます。
2. 左の欄に Markdown を書きます。右に、カーソルのあるスライドが表示されます。
3. 「▶ 最初から」または「▶ 現在のスライドから」を押すと、全画面で発表が始まります。

初めて開いたときは、書き方の説明を兼ねたサンプル(`demo_slides.md` と同じ内容)が入っています。
サンプルを書き換えた後でもう一度見たいときは、「開く」で `demo_slides.md` を開いてください。

## 生成 AI で原稿を作る

原稿がテキスト(Markdown)で、数式も LaTeX の書き方のまま書けるので、生成 AI が書いた原稿をそのまま貼るだけで、数式を含むスライドになります。

ChatGPT・Claude などの生成 AI に原稿を書いてもらうときは、最初に `prompt_for_ai.md` の中身を AI に渡してください。
このアプリで使える書き方(区切り、数式、段階表示、囲み枠など)が書かれているので、AI がこのアプリ用の書式で原稿を書きます。

1. `prompt_for_ai.md` の中身を AI に貼る(またはファイルを添付する)
2. 続けて、作りたい発表の内容を伝える(例:「〇〇について 15 分の発表スライドを作って」)
3. AI が書いた原稿を、左の欄に貼る
4. 右の表示と画面上部の警告を確認し、直したい点を AI に伝える

図は AI には作れないので、AI が「(図:…)」と書いた場所に、自分で画像を貼ってください。
画像を貼った原稿を AI に直してもらうときは、末尾の「以下は貼り付けた画像のデータ」の行から後ろを除いて渡してください。

## 書き方

画面上部の「書き方」ボタンでも一覧を見られます。

### 基本

| 書き方 | 結果 |
|---|---|
| `---`(この行だけ) | 次のスライドへ区切る(コードブロックと数式の中では区切らない) |
| `# 題名` | スライドの先頭に置くと表紙(中央寄せ)になる |
| `## 題名` | 通常のスライドの題名 |
| `- 項目` / `1. 項目` | 箇条書き / 番号付き。2 字下げで入れ子 |
| `**太字**` `*斜体*` `` `code` `` | 太字・斜体・等幅 |
| `++下線++` | 下線 |
| `[文字]{.red}` | 文字の色。`.red`・`.yellow`・`.blue` の 3 色(配色に合わせて見やすい色になる) |
| `> 引用` | 引用 |
| `| a | b |`(2 行目に `|---|--:|`) | 表(2 行目で左右の揃えを指定) |

段落の中の改行は、そのまま改行になります。
内容がスライドからはみ出すときは、本文の文字を自動で縮小します。題名(`##`)の大きさは変わりません。
エディタで Tab を押すと、空白 2 つが入ります。

### 数式

| 書き方 | 結果 |
|---|---|
| `$a^2+b^2$` | 行内の数式 |
| `$$`(改行)式(改行)`$$` | 別行立ての数式。`\[ … \]` でも書ける |
| `$\newcommand{\norm}[1]{\lVert #1\rVert}$` | マクロの定義。それ以降のすべてのスライドで使える |
| `\$` | ドル記号そのもの |

KaTeX にもともとある命令(`\R` など)を定義し直すときは、`\renewcommand` を使います。
`$$` や `\[` を閉じ忘れると、画面上部に行番号つきの警告が出ます。

### コード

````
```python
print("hello")
```
````

言語名を書くと色が付きます。使える言語は c, cpp, arduino, java, python, matlab, julia, fortran, bash, latex です。

### 段階表示

| 書き方 | 結果 |
|---|---|
| `+-+-+-`(この行だけ) | この行より後ろを、発表中の次のクリックで出す。1 枚に何回でも書ける |
| `\pause` | 別行立ての数式で行と行の間に書くと、式を 1 行ずつ出す(`&` による位置揃えは保たれる) |

`+-+-+-` は、段組(`:::cols`)の段の中や囲み枠(`:::box`)の中にも書けます。その段・枠の中の、その行より後ろが次のクリックで出ます。段の先頭に書くと、その段全体が後から出ます。出る順番は原稿の上から順です。
箇条書きでは、字下げしていない項目の間に書いてください(入れ子の途中には書けません)。コードブロックと数式の中の `+-+-+-` は区切りになりません。

← で 1 段階ずつ戻ります。編集中の右の表示と印刷では、全部を出した状態になります。

### 段組と囲み枠

```
:::cols 40 60
左の段
|||
右の段
:::
```

`|||` で段を区切ります。3 段以上にもできます。`40 60` は幅の比で、省略すると等分です。

```
:::box 定理
本文
:::
```

見出し付きの囲み枠です。見出しは自由に書けて、省略すると枠だけになります。段組や枠の中にも入れられます。

### 画像

| 操作 | 内容 |
|---|---|
| 画像ファイルを右のスライドにドロップ | その位置に貼る |
| Ctrl+V | クリップボードの画像を、カーソルのある行に貼る |
| 右のスライドで画像をドラッグ | 移動 |
| 画像をクリック → 四隅をドラッグ | 拡大縮小(縦横比は固定) |
| 画像を選んで Delete | 削除 |
| `![説明](画像.png)` | 画像ファイルや URL を参照する(`index.html` からの相対パスまたは URL) |

貼った画像は、本文に `![][img1]{x=… y=… w=…}` の形で自動で書き込まれます。
画像のデータそのものは、保存した `.md` の末尾にまとめて埋め込まれます。本文の見通しを悪くしないためです。
末尾の「以下は貼り付けた画像のデータ」の行から後ろは、編集しないでください。

## 発表

| 操作 | 内容 |
|---|---|
| クリック・→・↓・Space・Enter・PageDown | 次へ |
| ←・↑・PageUp・Backspace | 前へ |
| Home / End | 最初 / 最後のスライド |
| B | 画面を黒くする(もう一度 B、ほかのキー、クリックで戻る) |
| I | スライドの一覧(クリックでそのスライドへ。I か Esc で閉じる) |
| Esc | 発表を終える |

最後のスライドの次は終了画面になり、もう一度進めると発表を終えます。

マウスの位置には、朱赤のレーザーポインタが表示されます。
マウスやペンを動かすと、左下に道具が出ます。

| 道具 | 内容 |
|---|---|
| ポインタ | クリックで次へ進む(既定) |
| ペン | スライドに書き込む。ペンタブレットでは筆圧で太さが変わり、側面ボタンを押しながら書くと消しゴムになる |
| 消しゴム | 触れた線を一筆ごと消す |
| 色(4 色) | ホワイトボードアプリと同じ配色(黒板では白・朱赤・黄・青、それ以外では黒・赤・金・青) |
| 全消去 | このスライドの書き込みをすべて消す |
| 一覧 | スライドの一覧(I と同じ) |

ペンと消しゴムのときは、クリックしても次へ進みません。キーで進めてください。
書き込みはスライドごとに残り、発表を終えると消えます。

## 配色

画面右上の選択欄で選びます。選んだ配色はブラウザに保持されます(`.md` ファイルには保存されません)。

| 配色 | 内容 |
|---|---|
| 白 | 白地(既定) |
| 黒板 | 深緑の黒板とチョーク風の文字 |
| えんじ | えんじ色の帯の大学テンプレート風。表紙は別デザイン、右下にページ番号 |
| 紫紺 | えんじと同じデザインで、帯を紫紺(DIC-256)にしたもの |
| ペールブルー | えんじと同じデザインで、帯を淡い青にしたもの |

## 保存

| ボタン | 動作 |
|---|---|
| 新規 | 空のスライドで新しく始める |
| 開く | Markdown ファイル(`.md`)を開く |
| 上書き保存 | 開いているファイルに上書きする(まだファイルがないときは保存先を選ぶ) |
| 別名で保存 | 保存先とファイル名を選んで保存する |

Chrome と Edge では、開いたファイルにそのまま上書きします。ほかのブラウザでは、ダウンロードとして保存します。
ファイル名の後ろの `*` は、保存していない変更があることを示します。保存していない変更があるときに「新規」や「開く」を押すと、確認が出ます。

編集中の内容は、ブラウザの `localStorage` にも自動で保持されます。ページを閉じても、次に開くと続きから使えます。ただし、次の点に注意してください。

- 保持先はブラウザごと、サイト(URL)ごとです。別のブラウザや別の場所の `index.html` で開くと、別の保持先になります。
- ブラウザの「サイトデータの削除」で消えます。残したい原稿は、必ずファイルに保存してください。
- 画像を多く貼ると、ブラウザの容量の上限に達して保持できなくなることがあります。その場合は画面上部に警告が出ます。
- 同じ `index.html` を 2 つのタブで開いて編集すると、片方の内容がもう片方を上書きします。その場合も警告が出ます。

## 印刷 / PDF

「印刷 / PDF」を押すと、全スライドを 1 ページに 1 枚ずつ印刷します。送信先に「PDF に保存」を選ぶと PDF になります。
段階表示のスライドは、全部を出した状態で印刷します。発表中の書き込みは印刷されません。
1 ページに複数枚を並べたいときは、印刷画面の「1 枚あたりのページ数」などのプリンタ側の設定を使ってください。

## 動作環境

Edge・Chrome などの最近のブラウザで動きます。Chrome・Edge 以外では、上書き保存がダウンロードになります。
ネット接続が必要なのは、公開版のページを開くときだけです。ダウンロードした `index.html` は、接続しなくても動きます。ただし、`![説明](https://…)` のように URL で参照した画像の表示には接続が必要です。
