# Whiteboard — ブラウザだけで動く無限ホワイトボード

HTML ファイル 1 つで完結する、手描き専用のホワイトボード/黒板アプリです。インストール・アカウント・サーバー処理は不要で、`index.html` をブラウザで開くだけで使えます。

- 無限領域(パン・ズーム自由)
- ペンタブレット対応(筆圧、側面ボタンで消しゴム)
- 黒板モード(既定)と白板モードの切替
- スクリーンショットなどの画像を貼り付けて、その上に書き込める
- 複数ボードをブラウザ内に自動保存
- PNG / SVG(ベクトル)/ JSON(編集用)で書き出し

## 使い方

### Web 版

<https://board.sapp.jp> を開くだけで使えます。描いた内容はサーバーに送られず、利用者のブラウザ内にだけ保存されます。共同編集機能はありません。

### ローカルで使う

`index.html` をダウンロードし、ダブルクリックして Edge / Chrome / Safari / Firefox で開きます。通信は一切行いません。

## 操作

### 描画

| 操作 | 内容 |
|---|---|
| ドラッグ | 描画 |
| `1` / `2` / `3` / `4` | 色(黒(白)/ 赤 / 黄 / 青) |
| `E` または 消しゴムボタン | 消しゴム(触れた線を一筆ごと消す) |
| ペンの側面ボタンを押しながら描く | 消しゴム(ボタンを離すと描画に戻る) |
| 太さスライダー | 線の太さ(筆圧対応のペンでは筆圧でも変化) |
| `Ctrl+Z` / `Ctrl+Y`(← / →) | 元に戻す / やり直し |
| 全消去 | 今のボードの内容を空にする(元に戻せる) |

### 表示

| 操作 | 内容 |
|---|---|
| ホイール | ズーム(カーソル位置中心) |
| Shift+ホイール / Alt+ホイール | 横 / 縦スクロール |
| 中ボタンドラッグ / 右ドラッグ / Space+ドラッグ / `H`(移動ツール) | パン |
| タッチ 2 本指 | ピンチズーム・パン |
| 原点(`0`) | 初期位置・倍率 100% |
| 全体(`F`) | 描いた範囲全体を画面に収める |
| 白板チェックボックス | チェックで白い背景、外すと黒板(既定) |

### 画像

| 操作 | 内容 |
|---|---|
| `Ctrl+V` | クリップボードの画像を貼り付け(カーソル位置、なければ画面中央) |
| ファイルをドロップ | 画像ファイルを貼り付け |
| 移動ツールで画像をドラッグ | 移動 |
| 移動ツールで画像をクリック → 四隅のハンドルをドラッグ | 拡大縮小(縦横比固定) |
| `Delete` / `Backspace` | 選択中の画像を削除 |
| `Esc` | 選択解除 |

消しゴムは線だけを消し、画像は消しません。

### ボード

ツールバーの選択欄でボードを切り替えます。各ボードは独立した無限領域・表示位置・黒板/白板設定を持ちます。

| 操作 | 内容 |
|---|---|
| ＋ | 新しいボードを追加 |
| ▾ → 名前を変更… | ボード名の変更 |
| ▾ → このボードを削除… | ボードの削除(元に戻せません) |

### 保存・読込

| 操作 | 内容 |
|---|---|
| 保存 ▾ → PNG 画像 | 描画範囲全体をラスター画像で保存 |
| 保存 ▾ → SVG 画像(ベクトル) | 線をベクトル、貼り付け画像は埋め込みで保存。Inkscape などで PDF に変換可 |
| 保存 ▾ → JSON(編集用データ) | 線・画像・表示位置を含む完全なデータ。後で読み込んで続きを描ける |
| JSON 読込 | JSON を新しいボードとして追加(今のボードは残る) |

ファイル名はボード名 + 日時です。

## 自動保存について

一筆ごとにブラウザの `localStorage` に自動保存され、ファイルを閉じても再度開けば前回の続きから使えます。次の点に注意してください。

- 保存先はブラウザごと・サイト(オリジン)ごとです。別のブラウザや別の URL で開くと別の保存領域になります。ローカルの `file://` と Web 上の URL も別扱いです。
- ブラウザの「サイトデータの削除」で消えます。残したい板書は JSON 保存で退避してください。
- 容量はブラウザの上限(概ね 5 MB)をボード全体で共有します。画像を多く貼ると上限に達し、左下に自動保存失敗の表示が出ます。その場合は JSON 保存で退避し、不要なボードを削除してください。

## 講義での配布例

1. 講義後に「保存 ▾ → JSON」で板書を保存する。
2. JSON を学生に配る(LMS、メール、または Web サーバーに置く)。
3. 学生は <https://board.sapp.jp> を開き、「JSON 読込」で板書を開き、自分のメモを書き足す。追記は学生自身のブラウザに自動保存される。

学生の追記が配布元の JSON や他の学生に影響することはありません。

## 色の設計(カラーユニバーサルデザイン)

色はデータ上「黒・赤・黄・青」の 4 種で保存され、表示色だけを黒板/白板で切り替えます。表示色は P 型・D 型色覚のシミュレーション(Machado らの変換)で、背景とのコントラストと色同士の輝度差を確認して選んでいます。

| 色 | 黒板での表示 | 白板での表示 |
|---|---|---|
| 黒 | 白 `#f2f2f2` | 黒 `#000000` |
| 赤 | 明るい朱赤 `#ff7046` | 赤 `#d42040` |
| 黄 | 淡い黄 `#f8e070` | 金 `#d08a00` |
| 青 | 明るい青 `#5aa9ff` | 青 `#0066cc` |

黒板モードの配色は、カラーユニバーサルデザイン認証を受けた色覚対応チョーク(朱赤・黄・青を明度と彩度の差で見分けさせる考え方)に倣っています。

## 動作環境

Pointer Events と Canvas に対応したブラウザ(Edge、Chrome、Safari、Firefox の最近の版)。Windows + Wacom ペンタブレット、Mac + Safari で動作を確認しています。外部ライブラリ・外部リソースの読み込みはありません。
